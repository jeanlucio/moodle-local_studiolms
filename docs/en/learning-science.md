# 🔬 Learning Science Foundations

The rich visual output is not cosmetic: each kind of block is grounded in learning science.

**Multimedia Learning Theory, Richard Mayer (2001):** generated pages apply seven of Mayer's principles (signalling, segmenting, spatial contiguity, coherence, redundancy, pre-training and personalisation). The automatic "Key concepts" callout at the top of each page is a direct use of *pre-training*.

**Cognitive Load Theory, John Sweller (1988):** organised visual blocks (cards, grids, steps) reduce *extraneous* load and free capacity for *germane* load. A single course glossary means students always know where to look for a definition.

**Dual Coding Theory, Allan Paivio (1971):** infographics, charts and gauges use the visual channel while the text works through the verbal one.

**Universal Design for Learning, CAST (2002):** the same idea can be shown as text, a visual, a table or a diagram, which widens access across learning styles.

**Information Mapping, Robert Horn (1970s):** each kind of information has its best block: procedure to steps, chronological process to timeline, comparison to comparison, quantitative facts to stats, hierarchy to accordion, related items to grid cards, critical information to callout. The restyle uses the same idea to decide where a block belongs in a text you already wrote.
