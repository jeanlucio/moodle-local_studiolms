# 📦 Requirements

| Component | Version |
|-----------|---------|
| Moodle    | 4.5 and later |
| PHP       | 8.1 or later (the automated tests run on 8.1 to 8.4) |

At least one source of AI is needed to generate anything: the [AI Hub](https://github.com/jeanlucio/moodle-local_aihub) (`local_aihub`, a plugin by the same author) with a key, or a provider configured in Moodle's AI subsystem (`core_ai`). The wizard and the restyle show guidance when none is available. Everything else is optional: see [Integrations](#integrations).
