# 📦 Requisitos

| Componente | Versão |
|------------|--------|
| Moodle     | 4.5 ou superior |
| PHP        | 8.1 ou superior (os testes automatizados rodam no 8.1 a 8.4) |

É preciso ao menos uma fonte de IA para gerar qualquer coisa: o [Hub de IA](https://github.com/jeanlucio/moodle-local_aihub) (`local_aihub`, um plugin do mesmo autor) com uma chave, ou um provedor configurado no subsistema de IA do Moodle (`core_ai`). O assistente e a estilização mostram orientação quando nenhuma está disponível. Todo o resto é opcional: veja [Integrações](#integrations).
