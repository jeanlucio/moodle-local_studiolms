# 📦 Requisitos

| Componente | Versão |
|------------|--------|
| Moodle     | 4.5 ou superior |
| PHP        | 8.1 ou superior (os testes automatizados rodam no 8.2 a 8.4) |

É preciso ao menos uma fonte de IA para gerar qualquer coisa: o Hub de IA (`local_aihub`) com uma chave, ou um provedor configurado no subsistema de IA do Moodle (`core_ai`). O assistente e a estilização mostram orientação quando nenhuma está disponível. Todo o resto é opcional: veja [Integrações Opcionais](#integrations).
